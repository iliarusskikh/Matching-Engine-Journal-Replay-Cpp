Matching Engine Journal & Replay · Knowledge notes

Testing { Prove identical rebuild }

Unlike the gateway (where multi-shard logs are intentionally non-bit-stable), this project’s headline test is bit-identical live vs replay — plus loud failures on bad journals.

01

Test layers

LayerAssertsRole
LOB golden Matching rules still correct Vendored engine sanity (optional slim port of LOB tests)
Record / CRC unit Encode/decode round-trip; CRC vectors Format correctness without files
Identity Live events/book == replay events/book Core product promise
Integrity negatives Trunc / corrupt / bad magic → error Fail-closed behavior
Contrast with gateway

Gateway avoids golden-diffing multi-shard publisher logs (scheduler interleaving). Here the journal is a single ordered stream — identity diffs are the point.

02

Format & CRC units (write first)

  • NEW round-trip: host command → bytes → command.
  • CANCEL round-trip.
  • CRC known-answer test.
  • Flip one body byte → BadChecksum.
  • static_assert packed sizes still hold.

These tests unblock writer/reader without needing full scenarios.

03

Live vs replay identity

pattern
// 1) live match, collect events + book digest
auto live = run_live(scenario);

// 2) journaled run → file
auto path = write_journal(scenario);

// 3) replay file
auto replayed = replay_file(path);

expect(live.events == replayed.events);
expect(book_equal(live.engine, replayed.engine));

Start with one small scenario (exact fill) and one partial-fill + cancel. Reuse LOB DSL scenarios under scenarios/ when vendored.

04

Negative / integrity cases

CaseSetupExpect
Truncated tail Write good journal; chop last N bytes TruncatedRecord (or equivalent), non-zero
Corrupt CRC Flip a byte in last record body BadChecksum
Bad magic Overwrite header magic BadMagic
Unknown type Patch type byte to 0xFF BadType
Temp files

Write under build/ or a temp path; *.jnl is gitignored. Do not commit binary journals.

05

LOB goldens

Keep a thin lob_tests (or a few cases inside journal_tests) so a bad LOB vendor copy fails before you debug journal code. Matching bugs look like “replay ≠ live” but root cause is the engine.

06

What to assert (and not)

AssertSkip
Event type / id / qty / price fields Wall-clock timestamps (if present)
Best bid/ask and resting qtys Exact fsync timing
Error enum on bad files Performance SLAs in v1
07

Harness style

Match companions: hand-rolled expect(), no Catch2/GTest. CTest targets:

  • phase1_tests — vendored LOB smoke + scenario loader
  • journal_tests — CRC vector, encode/decode, trunc / bad checksum
  • identity_tests — live event lines ≡ replay
08

Decision

Decision

Identity is the primary oracle (live ≡ journaled live ≡ replay). Integrity negatives are first-class. Rejected: treating “it printed something” as success; rejected: requiring multi-process chaos tests in v1.
