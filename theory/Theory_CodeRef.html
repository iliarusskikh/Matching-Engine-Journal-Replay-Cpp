04

Binary & packing habits

  • Prefer explicit encode/decode functions over casting host structs to char* for the whole file.
  • static_assert(sizeof(NewBody) == …) next to packed structs.
  • Write multi-byte integers in documented endianness (LE for v1).
  • Never serialize bool as a raw compiler bool without fixing width — use uint8_t.
LE store helper sketch
inline void store_u64_le(uint8_t* p, uint64_t v) {
  for (int i = 0; i < 8; ++i)
    p[i] = static_cast<uint8_t>((v >> (8 * i)) & 0xff);
}
05

File I/O & RAII

Pattern from MDS sockets, applied to files:

  • Own the handle in a class; close in destructor.
  • Delete copy constructor/assignment; implement move if needed.
  • Check every write’s return length; short writes are errors.
  • Open journals with binary mode / O_RDONLY vs O_CREAT|O_TRUNC|O_WRONLY.
06

enum class & errors

Use scoped enums for CmdType and JournalError. Map to exit codes in CLIs (0 = success). Prefer returning status over throwing in the hot read loop (exceptions OK for “can’t open file” in main if you keep it consistent).

07

CLI & filesystem

  • Parse argv manually (no gflags) — same as other repos.
  • std::filesystem::path for -o run.jnl.
  • Print human errors to stderr; keep stdout for event lines if you pipe demos.
